### **Summary of Features and Technologies**

  - Approve teacher and student registrations.
  - Get analytics (graphs, top scores, averages, pass count, etc.) for exams.

- **Technologies:**
  - **Frontend:** ReactJS (for UI components like forms, tables, and dashboards), Chart.js or Recharts (for analytics graphs).

  - **Additional Tools:**

#### **2. Teachers**
- **Features:**
  - Register with details (department, college, etc.) and await admin approval.
  - Create exams (subject name, exam name, duration, marks) with quiz (auto-corrected) and subjective (manually corrected) questions.
  - Option to use an AI model (e.g., Gemini) to auto-grade subjective answers, with manual verification/editing of marks.
  - Modify exams, view student marks, and get analytics (all marks, top marks, average, pass/fail percentage, graphs).
  - View live exam proctoring (student camera feed).
  - Add questions manually (form) or by scanning an Excel file.
  - View malpractice logs and reports.

- **Technologies:**
  - **Frontend:** ReactJS (for exam creation forms, live proctoring dashboard), Webcam libraries (e.g., react-webcam for live monitoring).
  - **Backend:** ExpressJS (APIs for exam creation, answer submission, and proctoring logs), Multer (for file upload like Excel scanning).
  - **Database:** MySQL (store exams, questions, answers, malpractice logs).
  - **AI Integration:** Google Gemini API or similar (for subjective answer grading), integrated via ExpressJS.
  - **File Parsing:** XLSX (Node.js library to parse Excel files for question uploads).
  - **Proctoring:** WebRTC (for real-time video streaming of student cameras), Socket.IO (for live updates to teacher dashboard).
  - **Analytics:** Chart.js or Recharts (for graphical representation of marks).

#### **3. Students**
- **Features:**
  - Register with institution, course, and semester details, await admin approval.
  - View and attempt exams assigned to their semester.

  - Auto-submit after 3 warnings, log malpractice in a table.
  - View marks and performance reports.

- **Technologies:**
  - **Frontend:** ReactJS (exam interface, full-screen enforcement), react-webcam (for proctoring), Screenfull.js (for full-screen mode).
  - **Backend:** ExpressJS (APIs for exam retrieval, submission, and malpractice logging).
  - **Database:** MySQL (store student details, exam attempts, marks, malpractice records).
  - **Proctoring:**
    - WebRTC (for camera feed).
    - TensorFlow.js or OpenCV.js (client-side face detection for no/multiple persons).
    - Event listeners (to detect tab/window switching).
    - Socket.IO (real-time communication for warnings and auto-submission).
  - **Reports:** Chart.js (for performance graphs).
